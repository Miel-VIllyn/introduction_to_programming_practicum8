## Reflection
1 - Zorgt ervoor dat de main branch stabiel blijft terwijl elke collaborator apart kan werken.
2 - Beide branches hebben hetzelfde stuk aangepast, waardoor git niet kan weten welke aanpassing je wilt bij de merge.
3 - GitHub markeert de verschillen, waardoor we konden kiezen welke aanpassingen we willen houden en welke aanpassingen we willen wegdoen. Zo konden we het conflict zetten als 'resolved'
4 - Collaborators kunnen elkaars code bekijken, beoordelen en de foutjes eruit halen.
